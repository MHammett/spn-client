# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
v2.1. In short: be respectful, assume good faith, and keep disagreements
about the code, not the person.

Report anything that violates this to the maintainer directly via a GitHub
issue marked private, or GitHub's own reporting tools, rather than escalating
in a public thread.
